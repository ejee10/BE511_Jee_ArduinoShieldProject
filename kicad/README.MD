# BE511 Arduino Analog Shield

KiCad schematic and PCB layout for a 4-channel analog I/O shield for the Arduino Uno.
- 4 analog inputs: MCP3204 12-bit ADC with 50 kHz RC low-pass filters
- 4 analog outputs: 2x MCP4922 12-bit dual DACs
- SPI interface to Arduino
